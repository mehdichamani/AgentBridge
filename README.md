# 🛠️ Boomban Remote Workspace Guide

این محیط برای کار ریموت روی پروژه `boomban-suite` (سیستم مقصد `work`) از داخل **Antigravity IDE** طراحی شده است.

---

## 📁 ساختار پوشه

```text
boomban-remote/
├── mnt/             # 📂 محل مانت شدن فایل‌های پروژه ریموت (SSHFS)
├── mount.sh         # 🚀 اسکریپت اتصال و مانت خودکار
├── unmount.sh       # 🛑 اسکریپت قطع اتصال امن
├── remote-run.sh    # ⚡ اجرای مستقیم دستورات روی ویندوز مقصد (داخل پروژه)
├── proxy.sh         # 🌐 پروکسی SOCKS5 برای دسترسی به شبکه و وب‌سرویس‌های داخلی مقصد
└── README.md        # 📖 همین راهنما
```

---

## 🚀 ۱. نحوه شروع به کار (Mount)

برای متصل شدن و مشاهده فایل‌های پروژه در پوشه `mnt/`:

```bash
./mount.sh
```

- پس از اجرای این دستور، کل سورس‌کد در پوشه [mnt/](file:///home/unreal/projects/boomban-remote/mnt) در دسترس است.
- می‌توانید در Antigravity IDE مستقیم پوشه `boomban-remote/mnt` یا همین پوشه `boomban-remote` را باز کنید.
- ایجنت هوش مصنوعی به تمامی فایل‌های داخل `mnt/` دسترسی کامل خواندن و نوشتن دارد.

---

## 🛑 ۲. قطع اتصال (Unmount)

زمانی که کارتان با پروژه تمام شد:

```bash
./unmount.sh
```

در صورتی که فایلی باز باشد، این اسکریپت به صورت خودکار از فلگ Lazy Unmount (`fusermount -uz`) استفاده خواهد کرد.

---

## ⚡ ۳. اجرای دستورات روی سیستم ریموت (`remote-run.sh`)

از آنجا که سیستم‌عامل مقصد ویندوز است، برای بیلد، تست یا دستوراتی که باید روی ماشین ریموت اجرا شوند:

### الف) ورود به شل ریموت (مستقیماً در پوشه پروژه):
```bash
./remote-run.sh
```

### ب) اجرای یک دستور خاص:
```bash
./remote-run.sh npm test
./remote-run.sh git status
./remote-run.sh dir
```

---

## 🌉 ۴. ارسال فرامین به سوئیچ‌های سیسکو (`cisco-bridge.sh`)

پل سیسکو ابزار واسط برای ارسال مستقیم فرامین به سوئیچ‌های سیسکو با Fallback خودکار (`SSH Key` ➔ `SSH Password` ➔ `Telnet`) و دریافت اطلاعات از دیتابیس است:

```bash
# مشاهده لیست سوئیچ‌ها و وضعیت ثبت آن‌ها در دیتابیس
./cisco-bridge.sh list

# ارسال فرمان بدون نیاز به IP
./cisco-bridge.sh koreh "show version"
./cisco-bridge.sh it-miz "show interfaces status"
```

---

## 🌐 ۴. دسترسی به شبکه و کارهای شبکه‌ای مقصد

### تست پینگ و شبکه از مبدأ سیستم مقصد:
اگر می‌خواهید وضع پینگ یا شبکه مقصد را چک کنید، دستور را مستقیماً از طریق مقصد بفرستید:
```bash
./remote-run.sh ping 192.168.1.1
./remote-run.sh powershell -Command "Test-NetConnection -ComputerName 192.168.1.50 -Port 80"
```

### عبور دادن ترافیک لوکال از شبکه مقصد (SOCKS5 Proxy):
برای اینکه مرورگر یا دستورات لوکال شما مثل این باشد که داخل شبکه ریموت نشسته‌اید:

```bash
./proxy.sh
```
این دستور یک پروکسی محلی روی پورت `1080` باز می‌کند (`socks5h://127.0.0.1:1080`).

- **تست در ترمینال:**
  ```bash
  curl --socks5-hostname 127.0.0.1:1080 http://internal-server:8080
  ```
- **استفاده در مرورگر:** می‌توانید پروکسی مرورگر را روی `SOCKS5: 127.0.0.1:1080` بگذارید تا به پنل‌ها و وب‌سرویس‌های شبکه مقصد دسترسی داشته باشید.
